## Start the program

Open a terminal in the folder containing the Python file and run:

```powershell
python "assignment 1_FanYi.py"
```

The main menu appears:

```text
ASSIGNMENT ONE
1 - Turtle Drawing
2 - QA Bot
3 - Exit
Choose 1, 2 or 3:
```

Type a menu number and press **Enter**.

## 1. Turtle Drawing

Enter `1` to display the drawing. Close the drawing window to return to the main menu.

## 2. QA Bot

Enter `2` to start the bot. Type a keyword or an English question containing one of the following keywords, then press **Enter**:

| Keyword | Example question |
| --- | --- |
| HKU | `What is HKU?` |
| robot | `Tell me about a robot.` |
| jetson | `What is Jetson?` |
| ai | `What does AI mean?` |
| human | `What is a human?` |

Type `quit`, `exit` or `bye` to return to the main menu.

## 3. Exit

Enter `3` at the main menu to close the program.
